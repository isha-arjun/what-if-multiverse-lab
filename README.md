# WHAT IF? — Multiverse Lab

A fan-made, browser-based alternate-reality sandbox. Pick a character focus, a pivotal event and a decision; the rules-based engine generates a hypothetical branch, causal chain and timeline telemetry.

## Features
- Scenario generator combining characters, events, locations and decisions
- Searchable character, event and location index
- Causal metrics: timeline stability, threat, alliance cohesion and technology
- Branch timeline and outcome summaries
- Parallel-reality comparison
- Save up to 100 experiments in browser local storage
- Responsive layout; no build tools, backend, API key or external dependency

## Run it
Open `index.html` in a modern browser. To publish with GitHub Pages, open the repository's **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then save.

## About the scenario count
The current library contains 40 character entries, 20 events, 16 locations and 8 decision patterns, yielding **102,400** possible input combinations. Outcomes are generated from reusable rules; they are not thousands of manually authored stories or a prediction of canon.
